## 1. 고객사 리스트

### 1-1. 화면 구성 (위 → 아래)
```
┌─────────────────────────────────────────────────────────────┐
│ 고객사  전체 16곳                  [엑셀 내보내기] [+ 고객사 등록] │ ① 헤더
├─────────────────────────────────────────────────────────────┤
│ 전체 16 | 진행대기 0 | 도입준비 2 | 체험중 0 | 사용중 13 |      │ ② 상태 탭
│ 계약종료 0 | 계약해지 0 | 미전환 1 | 기타 0                     │
├─────────────────────────────────────────────────────────────┤
│ [🔍 시설명·코드·담당자·연락처·사업자번호 검색      ] [상세필터 ▾] │ ③ 검색
│ (적용 필터 칩)  지역: 남양주 ✕  알림: 갱신 확인 필요 ✕  [초기화]  │
├─────────────────────────────────────────────────────────────┤
│ 테이블                                                        │ ④ 리스트
├─────────────────────────────────────────────────────────────┤
│                    < 1 2 3 >                                 │ ⑤ 페이지네이션
└─────────────────────────────────────────────────────────────┘
```

### 1-2. 상세 필터 패널
| 필터 | 형태 |
|---|---|
| 지역 | 다중 선택 |
| 시설 유형 | 다중 선택 |
| 내부 담당자 | 다중 선택 (비활성 사용자 포함) |
| 알림 | 다중 선택: 갱신 확인 필요 / 갱신 취소 예정 / 자동연장 미승인 / 진행대기 장기 / 체험 종료 확인 필요 / 도입 지연 / 장비 미회수 / 청구 미처리 / 미납 / 담당자 재배정 필요 |
| 이번 달 청구 상태 | 청구 전 / 청구 완료 / 입금 확인 / 미납 |

| 등록일 | 기간 (Date Picker) |
| 계약 종료일 | 기간 (Date Picker) |

- [적용] 시 칩으로 표시, 칩 ✕로 개별 해제
- 검색어·탭·필터·정렬·페이지는 URL에 반영 → 새로고침·뒤로가기·링크 공유 시 유지

### 1-3. 컬럼 (모든 탭 동일)
탭을 바꿔도 컬럼 구성은 같음. 탭별 세부 정보(체크리스트 진행률, 체험 기간 등)는 상세 페이지에서 확인

| # | 컬럼 | 표시 내용 | 정렬 |
|---|---|---|:-:|
| 1 | No | 등록 순번 | ✅ |
| 2 | 시설명 | 시설명(굵게) / 아래 작게 고객사 코드 | ✅ |
| 3 | 상태 | 상태 배지 | ✅ |
| 4 | 알림 | 알림 배지 아이콘, 마우스 오버 시 내용 (없으면 빈칸) | |
| 5 | 시설 유형 · 지역 | "노인요양시설 · 남양주" | |
| 6 | 대표 담당자 | 이름(역할) / 아래 작게 연락처 — 여러 명이면 첫 번째 + "외 N명" | |
| 7 | 내부 담당자 | 이름 (비활성 시 회색 + "재배정 필요") | ✅ |
| 8 | 계약 종료일 | YYYY.MM.DD + 남은 기간("90일 남음"·"오늘 종료"·"3일 지남", 오늘 기준) (계약 없으면 "-") | ✅ |
| 9 | 월 비용 | 공급가 / 아래 작게 VAT 포함 (없으면 "-") | ✅ |
| 10 | 등록일 | YYYY.MM.DD | ✅ |
| 11 | 서비스 페이지 | ↗ 아이콘 버튼 (URL 없으면 비활성) | |

- 기본 정렬: 등록일 최신순
- 행 클릭 → 상세 페이지 이동 (서비스 페이지 버튼 클릭은 새 탭, 행 이동 안 함)
- 알림은 `알림` 컬럼의 배지로만 표시: ! 아이콘 + 색(빨강: 경과·미승인·미납·미회수 / 주황: 임박·확인 필요 / 회색 i: 안내) — 행 좌측 색 띠는 사용하지 않음
- 빈 상태: "조건에 맞는 고객사가 없습니다" + [필터 초기화]

### 1-4. 엑셀 내보내기
- 현재 탭·검색·필터 결과 전체(페이지 무관)를 내보냄
- 컬럼: 화면 컬럼 + 주소, 시설 담당자 전체, 사업자 정보, 정산 정보, 계약 정보, 비용 항목 요약
- 제외: 와이파이 비밀번호, 서비스 계정 비밀번호

## 2. 고객사 등록

- 한 페이지 폼, 섹션 구성: **기본(펼침)** / 시설 담당자(펼침) / 사업자 정보 · 정산 정보 · 설치 환경 · 서비스 운영(접힘)
- 필수: 시설명, 시설 유형, 지역, 내부 담당자, 시설 담당자 1명(이름·연락처), 대표 담당자 1명 이상(담당자별 체크, 첫 담당자 기본 체크) → 나머지는 등록 후 상세에서 입력 가능
- 고객사 코드는 선택(도입준비·체험중 전환 시 필수), 입력하면 저장 후 변경 불가 안내 표시
- 고객사 코드: 입력 즉시 중복 확인 표시
- 인바운드 문의에서 전환 시: 문의 내용으로 폼 자동 채움 + 문의 원문을 첫 히스토리로 저장
- [저장] → 상태 `진행대기`로 생성, 상세 페이지로 이동 / [취소] → 입력 내용 있으면 이탈 확인창

### 3-2. ① 헤더
| 요소 | 동작 |
|---|---|
| 시설명 · 코드 | 표시만 (수정은 기본정보 탭) |
| 시설 유형 · 지역 | 표시 |
| 상태 버튼 `[사용중 ▾]` | 클릭 → 상태 변경 모달 (5-1) |
| 알림 배지 | 갱신 확인 필요 / 갱신 취소됨 / 자동연장 미승인 등, 클릭 시 해당 모달 |
| 서비스 페이지 이동 | 새 탭, URL 없으면 비활성 + 툴팁 "기본정보에서 URL을 등록하세요" |

### 3-3. ② 안내 배너 (해당될 때만, 여러 개면 세로로 쌓임)
| 조건 | 문구 | 액션 |
|---|---|---|
| 필수 서류 누락 (도입준비·사용중) | "필수 서류가 누락되었습니다: 계약서, 디바이스 인수증" (빨강) | `문서 탭으로` |
| 갱신 취소됨 | "YYYY.MM.DD에 계약이 종료됩니다." | `계약 기간 변경` → 5-5 |
| 자동연장 미승인 | "계약이 동일 조건으로 자동연장되었습니다. 확인이 필요합니다." | `확인하기` → 5-4 |
| 도입준비 + 사용중 필수 항목 미입력 | "사용중 전환 전 입력이 필요한 항목이 N개 있습니다." | `확인하기` → 누락 항목 목록 |
| 내부 담당자 비활성 | "내부 담당자가 비활성 상태입니다. 담당자를 재배정하세요." | `재배정` |
| 체험 종료 D-7 이내·경과 | "체험이 YYYY.MM.DD에 종료됩니다." / "체험 기간이 경과했습니다." | `체험 결과 처리` → 5-8 |
| 회수·종료 체크리스트 미완료 | "장비 회수 등 종료 처리가 완료되지 않았습니다. (2/4)" | `체크리스트 탭으로` |
| 이번 달 청구 미처리 | "M월 세금계산서가 업로드되지 않았습니다." | `청구 탭으로` |

### 3-4. ③ 요약 카드
- 대표 담당자: 이름(역할), 여러 명이면 "외 N명", 클릭 시 대표 담당자 전원의 연락처 표시·복사
- 내부 담당자
- 계약 기간: 종료일 + 남은 기간("90일 남음", 오늘 기준 — D-day 표기 대신) (계약 없으면 "-")
- 계약 인원
- 월 비용: 공급가 / 아래 VAT 포함 작게 (일시 비용만 있으면 "월 비용 없음")
- 관리자 계정: 대표 관리자 ID + 복사 버튼, 아래 작게 "사용 계정 N개" (클릭 시 기본정보 > 서비스 계정으로 이동)
- 상태가 진행대기·미전환이면 계약 관련 카드 대신 `유입 채널 · 최근 활동일` 표시

### 3-5. ④ 탭 — 기본 선택 탭
| 상태 | 처음 열리는 탭 |
|---|---|
| 진행대기 · 미전환 | 기본정보 (미전환 + 회수 체크리스트 미완료 시 체크리스트) |
| 도입준비 | 체크리스트 |
| 체험중 · 사용중 | 계약·비용 |
| 계약종료 · 계약해지 · 기타 | 기본정보 (회수·종료 체크리스트 미완료 시 체크리스트) |

### 3-6. ⑤ 히스토리 패널 (우측 고정)
> 역할 구분 — **패널**: 다른 탭을 보면서 기록 입력 / **히스토리 탭**: 넓은 화면에서 전체 히스토리 읽기

- 기록 입력(상단): 유형(미팅/통화/메일/방문/기타) · 날짜(기본 오늘) · 내용 · [기록]
- 최근 기록 10건(자동·수동), [히스토리 탭에서 전체 보기]
- [≫] 버튼으로 접기·펼치기, 접힘 상태는 사용자별 기억
- 히스토리 탭을 보고 있을 때는 패널 자동 접힘(중복 표시 방지)
- 폭: 약 320px

## 4. 탭별 화면

### 4-1. 기본정보
섹션 카드 7개, **섹션별 [수정]** → 해당 섹션만 편집 모드 → [저장] / [취소]

| 섹션 | 표시 항목 |
|---|---|
| 기본 | 시설명, 고객사 코드(입력 후 변경 불가), 시설 유형, 지역·주소, 정원, 내부 담당자, 유입 채널, 메모 |
| 시설 담당자 | 표: ★대표(클릭으로 지정·해제, 여러 명 가능) · 이름 · 역할 · 직책 · 연락처 · 이메일 · 메모 · [수정][삭제] / [+ 담당자 추가] |
| 사업자 정보 | 운영 법인명, 사업자등록번호, 대표자명 |
| 정산 정보 | 청구일, 결제 수단, 세금계산서 발행 여부·이메일, CMS 회원번호·연동 여부 |
| 설치 환경 | 층수, 생활실 수, 와이파이 SSID, 비밀번호(`••••` [보기] [복사]), 네트워크 메모 |
| 서비스 운영 | 서비스 페이지 URL |
| 서비스 계정 | 표: ★대표 · 계정 ID(복사) · 유형 · 사용자 · 발급일 · 상태 · 비밀번호(`••••` [보기][복사], 미입력 시 "-") · 메모 · [수정][삭제] / [+ 계정 추가] / 필터: 사용·비활성 |

- 대표 담당자 = 실무·주 소통 담당자 표시(시설 대표자와 무관), 추가·수정 모달에서도 지정 가능
- 대표 담당자는 1명 이상 필수 — 마지막 대표의 해제·삭제는 "대표 담당자는 1명 이상 지정해야 합니다" 안내 후 차단, 대표가 없는 고객사에 담당자를 추가하면 자동으로 대표 지정
- 시설 담당자가 1명뿐이면 삭제 불가 — "시설 담당자는 1명 이상 있어야 합니다" 안내
- 서비스 계정의 대표 관리자 계정은 1개, 다른 계정이 있으면 대표 계정은 삭제 불가

### 4-4. 체크리스트
도입 체크리스트와 회수·종료 체크리스트를 한 탭에 표시 (진행 중인 체크리스트가 위로)

**도입 체크리스트**
```
설치 예정일 [2026.05.28]                          진행률 ███████░░░ 7/11

 ☑ │ 항목              │ 완료일     │ 완료자
 ☑ │ 입소자 정보        │ 2026.05.10 │ 김상수
 ☐ │ 시설 정보(wifi 등) │     -      │   -
 ☐ │ 계정 생성 (등록 계정 3개) │  -   │   -
 …
```

**회수·종료 체크리스트** (미전환·계약종료·계약해지 시 생성)
```
종료 처리  2026.12.31 계약종료                        진행률 ██░░ 2/4

 ☑ │ 장비 회수          │ 2027.01.05 │ 김상수 │ [회수 내역 ▸]
 ☐ │ 늘케어 계정 비활성화 │     -      │   -    │ [일괄 비활성 처리]
 ☐ │ 개인정보 파기       │     -      │   -    │
 ☑ │ 최종 청구 확인      │ 2027.01.03 │ 김상수 │

 회수 내역 ▾
  기기   │ 제공 │ 회수 │ 미회수 사유
  밴드   │ 80   │ 78   │ 분실 2
  허브   │ 10   │ 10   │
  차저   │ 10   │ 10   │
  회수일 [2027.01.05]
```
- 체크 즉시 저장 + 완료일(기본 오늘)·완료자 기록, 해제 시 확인창 → 완료일·완료자 삭제
- 완료된 항목의 완료일 칸은 Date Picker — 실제 완료한 날로 수정 가능(오늘 이후 불가), 히스토리 기록
- 메모 컬럼 없음 (컬럼: 체크 · 항목 · 완료일 · 완료자, 종료 체크리스트는 항목별 액션 링크 추가)
- 이관 데이터의 완료자는 "이관"으로 표시
- 장비 회수는 회수 내역 입력 후 체크 가능
- 미전환은 `장비 회수` 1개 항목만 표시

### 4-5. 문서
```
[문서]                                   PDF·이미지만 · 항목당 파일 1개 · 최대 20MB
 서류명          │ 등록     │ 파일명            │ 업로드            │  (필수 서류는 서류명 옆 빨간 *)
 계약서          │ 필수 │ ● 등록됨 │ 계약서_hbnh.pdf    │ 김상수 · 2026.05.28 │ [다운][교체][삭제]
 디바이스 인수증 │ 필수 │ ○ 미등록 │ -                 │ -                │ [업로드]
 사업자등록증 · 통장사본 · 도면 · 입소자 명단 │ 선택 │ … 같은 행 형태
 설치 사진       │ 추가 │ ● 등록됨 │ 설치_1층.jpg       │ …                │ [다운][교체][삭제]  ← [자료 추가]로 만든 행
                                                                    [+ 자료 추가]
```
- 필수 서류 누락 경고는 **상세 상단 배너에만** 표시 (문서 탭 안에는 없음, 도입준비·사용중)
- 서류 1개 = 1행, **항목당 파일 1개** (도면 포함)
- 가로 스크롤 없이 화면 폭에 맞춤: 열 폭 고정, 긴 파일명·서류명은 … 처리(마우스를 올리면 전체), 업로드는 이름 · 날짜(일 단위), 용량 표시 없음, [보기] 없이 [다운]
- [자료 추가]: 서류명 직접 입력 + 파일 선택 → 행 추가 (빈 행은 만들지 않음, 삭제하면 행도 없어짐)
- 계약서는 현재 계약 기준: 계약이 없으면 "계약을 먼저 등록하세요", 이전 계약의 계약서는 계약·비용 탭 이전 계약에서 열람
- [교체]: "기존 파일은 삭제되며 복구할 수 없습니다" 확인 후 새 파일 선택 (버전 보관 없음)
- 필수 서류 삭제 시 확인창에 "필수 서류입니다" 경고 (상태는 유지)
- 입소자 명단: 열람·다운로드 시 히스토리에 기록

### 4-6. 장비
**1차 (현재 범위) — 제공 수량만 기록**
```
                                                  [수량 수정]
 기기   │ 계약 제공 │ 추가 제공 │ 체험 제공 │ 합계 │ 회수
 밴드   │    80    │    2     │    0     │  82  │  -
 허브   │     0    │    0     │    0     │   0  │  -
 차저   │    10    │    0     │    0     │  10  │  -
 어댑터 │    10    │    0     │    0     │  10  │  -
 
 [옵션상품]                                   [+ 옵션상품 추가]
 구분 │ 제품명·모델 │ 수량 │ 제공일 │ 회수
```
- [수량 수정]: 계약 제공·체험 제공 칸을 표에서 바로 수정 → 저장 시 계약(또는 진행 중인 체험) 장비 수량에 반영 + 히스토리 기록
  - 계약 수량이 바뀌면 금액도 바뀜(구독료 = 밴드 수 × 월 단가, 구축 총액 = 단가 × 수량) → 수정 중 "계약 금액이 바뀝니다: 월 구독료 150,000 → 200,000원" 미리 표시
  - 계약에는 어댑터가 없으므로 어댑터 행의 계약 제공은 "-" (추가·체험 제공만)
  - 체험 제공 = 계약으로 전환되지 않은 체험 수량(회수 체크리스트와 같은 기준), 수정은 진행 중인 체험만
- 추가 제공은 추가 기기 제공 내역 합산값이라 여기서 수정 불가 (계약·비용 탭 > 추가 기기 제공에서 관리)
- 회수는 회수 체크리스트 값
- 옵션상품은 계약·비용 탭과 같은 데이터: 어느 탭에서 추가해도 양쪽에 표시(같은 입력 창), 금액·수정·삭제는 계약·비용 탭에서 관리

**2차 (장비관리 개발 후)**
- [수량 수정] → [장비 관리에서 수정 →]으로 교체
- 수량 숫자 클릭 → 해당 고객사에 매핑된 장비 목록(디바이스 ID·시리얼·매핑일·상태·배정 입소자)
- 매핑 흐름: 장비 입고·등록 → 고객사 매핑(연속 번호 범위 선택, 예: 101~103) → 입소자 매핑

### 4-7. 히스토리
- 넓은 화면에서 전체 히스토리를 읽는 용도
- 상단 입력 폼: 유형 · 날짜 · 내용(여러 줄) · [기록]
- 필터: 전체 / 자동 / 수동 + 유형 + 기간 + 작성자
- 타임라인(최신순): 날짜 구분선, 자동(●)·수동(✎) 아이콘, 작성자, 내용 전체
- 본인 수동 기록만 [수정] 노출, 수정 시 "수정됨" 표시

## 8. 버튼 동작 원칙
- 추가 버튼 → 입력 모달(필수 항목 누락 시 저장 차단), 수정 버튼 → 기존 값이 채워진 수정 모달, 삭제 → 삭제 확인 모달
- 상태 변경 → 도착 상태별 입력 모달(계약정보·체험 기간·종료일·해지 사유 등) → 변경 후 화면 즉시 반영
- 보기 → 미리보기 모달, 이전 버전 → 버전 목록 모달, 청구 내역 → 내역·금액 조정 모달
- 비활성화 → 확인 모달, 로그인 기록 → 기록 모달

## 9. 마이페이지
> 진입: 상단 헤더 우측 내 계정(이름) 클릭 → 드롭다운 [마이페이지] [로그아웃]
