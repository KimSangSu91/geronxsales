# 엑셀 → 시스템 이관 매핑표 (v0.2)

> 원본: `고객관리.xlsx` Sheet1 (2행 헤더, 3행부터 데이터 / 24행 — 완료 13 · 진행 중 2 · 중지 1 → **고객사 16곳**, 문의 접수 8 → **인바운드 문의함**)
> v0.2 변경: 고객사 문의접수 상태 제거에 따라 "문의 접수" 8행은 인바운드 문의함(미처리)으로 이관 (5장)
> 원칙: 원본은 수정하지 않음 · 이관 스크립트는 dry-run 결과 확인 후 실행 · 이관 데이터에는 상태 전환 규칙(서류 필수 등) 미적용

## 1. 컬럼 매핑

| 엑셀 컬럼 | → 시스템 필드 | 변환 규칙 |
|---|---|---|
| 단계 | 고객사.상태 | 진행 중→도입준비 / 완료→사용중 / 중지→미전환 / **문의 접수→고객사로 만들지 않고 인바운드 문의함으로(5장)** |
| 시설명 | 고객사.시설명 | 괄호 메모 분리: "고양서울요양원(내년6월)" → 시설명 `고양서울요양원`, 메모 `내년6월` |
| 담당자 | 시설 담당자.이름·직책 (대표) | "이정애 간호팀장" → 이름 `이정애`, 직책 `간호팀장`, 역할은 직책으로 추정(간호→간호) 후 검수 / "간호팀 공용폰"처럼 사람 이름이 아니면 이름 칸에 그대로 |
| 번호 | 시설 담당자.연락처 | 형식 통일 010-0000-0000 |
| 히스토리 | 수동 히스토리 1건 (유형: 기타, 작성자: 이관) | 원문 그대로 보존 + **계약 조건은 사람이 비용 항목으로 옮겨 입력** (예: 달명 가입비 30만·월 15만·후불, BMCO 1년 120만 일시) |
| 🔗 | 문서 (드라이브 파일 이관) | 드라이브 폴더 파일을 내려받아 슬롯별 업로드(계약서·인수증·도면·입소자 명단·기타) — 수작업 또는 반자동 |
| 지역 | 고객사.지역 | 그대로 ("성남위례", "경북경주" 등 표기 통일 필요) |
| 미팅 | 체크리스트 일정.미팅일 | 날짜 |
| 계약일 | 계약.계약일 | 날짜 |
| 설치일(예정일) | 체크리스트 일정.설치 예정일 | 날짜, 사용중이면 계약 시작일 기본값으로도 사용 |
| 도메인키 | 고객사.고객사 코드 | 소문자·숫자 검증 (문의 접수 8행은 문의함 이관이라 해당 없음) |
| 정원 | 고객사.정원 | 숫자 |
| 계약user | 계약.계약 인원 | 숫자 |
| 허브 수 / 밴드 수 / 충전기 수 | 계약.계약 장비 수량 | 숫자, 어댑터는 엑셀에 없음 → 빈 값 |
| 입소자 정보 ~ 테블릿&TV (11개) | 체크리스트 항목 완료 여부 | TRUE → 완료(완료일 비움, 완료자 `이관`) / FALSE·빈칸 → 미완료 |
| 비고 | 고객사.메모 | 그대로 |
| 1행 인바운드 시트 링크 | - | 이관 제외 (인바운드 문의함 구축 시 별도 검토) |

## 2. 엑셀에 없어 이관 전 채워야 할 값

| 시스템 필수 필드 | 처리 |
|---|---|
| 시설 유형 | 일괄 `노인요양시설`로 넣고 이관 후 검수 (재가센터 등은 수정) |
| 내부 담당자 | 담당자 지정표를 받아서 입력, 없으면 기본 담당자 1명 (이관 전에 사용자 계정부터 생성) |
| 계약 종료일 | 사용중 13곳 대부분 없음 → **이관 후 필수 보완 목록**으로 제공 (없으면 갱신 알림이 동작하지 않음) |
| 비용 항목 | 히스토리의 계약 조건을 보고 수기 입력 |

## 3. 이관 후 검증 리스트
- 고객사 수 16건, 상태별 건수(사용중 13 / 도입준비 2 / 미전환 1) 일치
- 인바운드 문의 8건(미처리) 일치
- 고객사 코드 중복 0건, 도입준비 이상 상태의 코드 누락 0건
- 사용중 고객사 중 계약 종료일 누락 목록 → 보완
- 사용중 고객사 중 계약서·인수증 미업로드 목록 → 드라이브 이관으로 보완
- 체크리스트 완료 개수 원본과 일치
- 장비 수량 합계(허브·밴드·충전기) 원본과 일치

## 4. 고객사 코드
- 사용중 이관 건은 단계별 필수 항목 누락 목록을 함께 출력해 보완

## 5. "문의 접수" 8행 → 인바운드 문의함
고객사로 만들지 않고 미처리 문의로 넣음 → 문의함에서 검토 후 [고객사로 전환](진행대기로 생성) 또는 [제외]

| 엑셀 컬럼 | → 문의(Inquiry) 필드 | 변환 규칙 |
|---|---|---|
| 시설명 | 시설명 | 괄호 메모는 내용에 포함 |
| 담당자 | 담당자명 | 원문 그대로 ("이정애 간호팀장") — 전환 시 이름·직책으로 나눠 입력 |
| 번호 | 연락처 | 형식 통일 010-0000-0000 |
| 지역 | 지역 | 그대로 |
| 히스토리 · 비고 · 미팅 | 내용 | 원문을 줄바꿈으로 합침 ("[히스토리] … / [비고] … / [미팅] YYYY-MM-DD") |
| (없음) | 채널 | 기타 |
| (없음) | 접수일시 | 미팅일이 있으면 미팅일, 없으면 이관일 |
| 행 전체 | 원본(raw) | 엑셀 행 원본 보관 |

- 상태는 미처리(NEW). 인바운드 문의함은 4단계에 구현 → **문의 8건 이관은 그때 실행**
- 이미 같은 시설명의 고객사가 있으면 이관하지 않고 목록으로 출력해 확인
